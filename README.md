# EHANK-SovRisk

This repository contains code and data for the project on sovereign risk in an EHANK (Extended Heterogeneous Agent New Keynesian) framework.

## 👥 Authors
- Boris Chafwehe
- Francesca Diluiso
- Guillaume Schwegler

## 📁 Folder Structure

- `data/` – Raw and processed data (raw data is excluded from Git)
- `code/` – Source code, organized by language (MATLAB, Stata, R, Python, etc.)
- `output/` – Figures, tables, results
- `manuscript/` – LaTeX paper source
- `logs/` – (Optional) Logs and temporary files

## 🛠️ Requirements
- Python 3.12 with packages from `requirements.txt`
